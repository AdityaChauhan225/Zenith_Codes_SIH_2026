# IMD Raw Data Directory

Place original, unmodified IMD (India Meteorological Department) station or gridded rainfall datasets here (e.g. `imd_rainfall_grid_2020_2024_raw.csv`).

## Policy Rules
- **NEVER** modify or overwrite original source files placed in this directory.
- Processed, normalized files will be written to `data/processed/` by `training/import_official_historical.py`.
